G.U.R.T. — Guided Unified Reactive Technology

Or, more descriptively:

G — Guided
→ Operates under user direction; voice-first, purpose-driven assistant

U — Unified
→ Combines voice interaction, AI reasoning, and vision-triggered presence detection

R — Reactive
→ Responds intelligently and promptly to user speech and presence

T — Technology
→ Powered by modern tools: Python, OpenCV, OpenAI, and ICP

## Sprig game: FNAF-inspired prototype

A reverse-engineered **Five Nights at Freddy's** style game for the Sprig toolkit is included at:

- `games/fnaf_sprig.js`

### Controls

- `i` toggle camera monitor
- `w/s` change cameras (while monitor is up)
- `a` toggle left door
- `d` toggle right door
- `j` left light flash
- `l` right light flash
- `k` restart after win/loss

### Mechanics included

- Power drain with usage levels
- Door/light/camera resource tradeoffs
- AI-based enemy movement checks (Bonnie, Chica, Freddy, Foxy)
- Foxy pirate cove pressure mechanic
- Survive-until-6AM timer win condition
